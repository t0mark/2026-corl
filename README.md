# CoRL 2026 한국어 가이드

CoRL 2026 (2026.11.9–12, Austin, TX) 참가자를 위한 비공식 한국어 정리 페이지.

- `index.html` — 홈 / 일정(KST 병기) / 논문 리스트(687편 검색·필터·관심 논문) / 키노트 / 워크숍 / 행사 / 참가 가이드
- `papers.js` — 채택 논문 데이터 (제목, OpenReview ID, 포스터 세션·번호, Oral/Spotlight 세션, 키워드 기반 주제 태그)

빌드 없이 `index.html`을 브라우저로 열면 됩니다. GitHub Pages로도 바로 배포 가능합니다.

출처: https://2026.corl.org/ (2026-11-07 기준)
